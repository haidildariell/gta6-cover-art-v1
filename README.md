Built for the [Make GTA 6 Cover Art bounty on make.fun](https://make.fun/bounty/gta6-cover-art-01).

Sunset Cover Studio is an offline web app that turns a photo plus a caption into GTA-style multi-panel cover art, with 8 layouts, colour grades, lettering, undo/redo, and PNG export at 1080x1080, 1080x1350, and 1920x1080.

To run it, serve the `app/` directory with any static server and open `index.html` — no build step or network needed.
